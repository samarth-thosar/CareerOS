# Cover letter source of truth

This file is the **voice and angle** for generated cover letters. The achievement bank
(`data/master/achievements.yaml`) supplies the *facts*; this supplies *how you sound and what you care about*.

Same rule as the resume: cover letters may only draw on facts from the achievement bank and profile. This file
shapes the framing, never adds claims. If a letter would need something not in the bank, you get a gap flag
instead of an invented sentence.

Everything marked **TODO** is a placeholder — replace it. Editable in the dashboard at `/profile`.
